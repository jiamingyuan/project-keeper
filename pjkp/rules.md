# project-keeper 规则

以下约束来自本对话用户指令；当前任务范围在版本记录中，不在这里保留永久授权。

- 项目是软件项目的知识补充，维持 Skill 形态与现有注册位置。项目资料各自存于根目录 pjkp/，不集中进 Skill 安装目录。（用户初始化与形态选择）
- 愿景、约束和 todo 只收用户提出或明确采纳的内容；候选、已确认决定和实际结果不得混淆。（用户规划来源要求，V0.2 定义）
- 版本编号由用户指定：Vx.x，小改调整后一个数字、大改调整前一个数字；同名版本先核对再续接。（用户版本约定）
- V0.1 是发布基线，不移动该标签、不追造开发或验收历史；V0.2 的结果不自动等于用户验收、发布或部署。（用户基线要求与 V0.2 定义）
- 原设计资料 `/Users/jiamingyuan/Desktop/workspaces/project-keeper/docs/`、idea-keeper 与其他项目数据不在本项目迁移范围。其他旧项目只有其用户要求时才迁移。（用户保留原数据要求）

当前有效内容优先；用户明确取代的旧要求移入版本历史。日期与来源仍不足以判定的冲突，应询问，不自行升级 Agent 建议。
