# project-keeper 规则

以下为用户对 project-keeper 本身提出的持续原则与边界；实现与执行纪律见 [Skill](../SKILL.md)，当前任务范围不在这里保留。

- 项目资料各自存于根目录 pjkp/，不集中进 Skill 安装目录。（用户初始化与项目资料随项目保存的要求）
- 愿景、约束和 todo 只收用户提出或明确采纳的内容；候选、已确认决定和实际结果不得混淆。（用户规划来源要求，V0.2 定义）
- 版本编号由用户指定：Vx.x，小改调整后一个数字、大改调整前一个数字；同名版本先核对再续接。（用户版本约定）
- V0.1 是发布基线，不移动该标签、不追造开发或验收历史。（用户基线要求）
- 项目记忆区分项目本身的原则与 Agent 工作规则，尊重用户指定入口，不自动双写；当前实现不自动升格为项目规则。（2026-10-26 用户对 AGENTS.md 与 rules 职责的明确区分及本轮修改指令，见[决定来源](V0.4/iteration.md#决定来源)）

本轮移出的实现事实、旧迁移范围及原文来源保留在[版本记录](V0.4/iteration.md#变化与归位)，不删除历史。
