## 上下文读取量

运行 `python3 -B tests/measure_context.py` 可重现。初始化采用全新项目；执行/测试采用两个历史版本与一个当前版本，另有 60 条历史日志；undo 时关闭当前版本并读取该次操作记录。

全量基线包含全部运行说明、模板、项目文档、历史和恢复材料；按需方案计算完整选中说明/文档，以及导航 JSON 的额外开销。没有把输入仅压成摘要后假设信息等价。数值为 UTF-8 字节，不是 token；时间戳等可造成轻微变化。

| 场景 | 全量读取 bytes | 按需读取 bytes | 减少比例 |
| --- | ---: | ---: | ---: |
| 初始化 | 28,703 | 15,003 | 47.7% |
| code-execute | 99,804 | 25,259 | 74.7% |
| test-execute | 99,804 | 25,259 | 74.7% |
| undo | 111,986 | 42,461 | 62.1% |

读取清单由测量脚本输出：

- 初始化：入口、项目操作、通用 CLI 与项目级模板，不读版本执行和关闭细节。
- 执行/测试：入口、执行组说明、通用 CLI、index/rules/brief、相关架构、当前版本材料与关联代码，不读旧版本全文和历史日志。
- undo：入口、关闭说明与关闭 CLI、需要的项目更新说明、当前文档和目标操作快照，不读所有历史快照。

测量后修正了导航本身的膨胀：默认不列历史日志所有标题，不展开所有旧版本；关闭专用 CLI 另行加载。信息仍在原文件中，可通过版本、章节、日志 id 和操作 id 定位；导航或摘要不替代事实与执行依据。

## 已知限制与尚待试用

- 自动化验证证明的是机械约束和样例行为，不是复杂项目中 Agent 理解、规划和测试设计的质量。本轮未进行独立模型端到端评测。
- record 和验收参数是调用者对证据/用户消息的记载，没有用户身份认证，也无法识别所有伪造事实。
- 指纹只覆盖列出的实现文件及相关材料，不自动捕获未列文件、外部服务或环境变化；Agent 必须核对真实覆盖。
- undo 遇到后续编辑会保守报冲突，需要 Agent 提出语义合并，必要时向用户确认；不声称自动合并任意冲突。
- 写锁只协调本脚本，单文件原子替换不等于跨文件事务；正常进程中断可续接，但不承诺断电或恶意竞态下的全盘事务保证。异常退出残留锁需核实后处理。
- 原始信息保留和按需导航已实现；实际上下文命中率、跨对话接续效果、token/耗时收益需要真实项目试用，不能从字节统计直接推出。
